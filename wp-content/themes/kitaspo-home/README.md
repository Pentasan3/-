# 北九州スポーツ整骨院 公式ホームページ WordPress テーマ（kitaspo-home）

LP（ペライチ）が縦に長く読みづらいという課題に対し、**要点だけを1画面ずつコンパクトにまとめた**公式ホームページ用テーマです。スポーツ障害専門の整骨院らしい、スピード感のあるネイビー×オレンジのデザインです。

## ページ構成（トップページ）

| セクション | 内容 |
|-----------|------|
| ヒーロー | キャッチコピー「スポーツのケガを、最短でプレー復帰へ。」＋「北九州で唯一のケアステーション」＋ 電話/LINE予約ボタン |

| メニュー・料金 | 保険施術／骨盤矯正／スポーツストレッチ（25分5,500円）／酸素カプセル／交通事故施術 |

## セットアップ手順

### 1. テーマのインストール

`kitaspo-home-theme.zip` を管理画面「外観」>「テーマ」>「新規追加」>「テーマのアップロード」からアップロードし、有効化してください。
（または `wp-content/themes/kitaspo-home/` フォルダをFTPでアップロード）

### 2. サイト基本設定

「設定」>「一般」でサイトのタイトルを「北九州スポーツ整骨院」、キャッチフレーズを設定してください（メタディスクリプション・OGPに使われます）。

### 3. 院情報の確認・変更

「外観」>「カスタマイズ」>「院情報」で以下を編集できます（初期値入力済み）。

- 電話番号（初期値: 093-967-9009）
- 住所（初期値: 〒803-0856 福岡県北九州市小倉北区弁天町5-8）
- アクセス（初期値: JR南小倉駅から徒歩1分）
- LINE公式アカウントURL / Instagram URL / ブログURL / GoogleマップURL
- 定休日・営業時間の補足

> ⚠️ **営業時間・料金は必ずご確認ください。** 営業時間の表は `front-page.php` の「営業時間・アクセス」セクションに直接記載しています。変更がある場合はこのファイルを編集してください。
>
> ⚠️ **「患者様の声」は仮のテキストです。** LP掲載の実際のお声が画像から判読できなかったため、内容を要約した仮テキストを入れています。`front-page.php` の `$voices` 配列を実際にいただいた声に差し替えてください。骨盤矯正・酸素カプセルの料金も同ファイルで編集できます。

### 4. お知らせの投稿

通常の「投稿」がトップページの「お知らせ」欄に最新3件表示されます。「設定」>「表示設定」で「投稿ページ」を設定すると一覧ページも使えます。

### 5. メニューの設定（任意）

「外観」>「メニュー」で「メインナビゲーション」「フッターナビゲーション」を設定できます。未設定の場合はページ内リンク（対応症状／選ばれる理由／メニュー・料金／アクセス）が自動表示されます。

## 特徴

- 予約導線を最優先：ヘッダー・ヒーロー・ページ末尾・モバイル画面下部固定バーの4箇所に電話/LINEボタン
- スマホ対応（レスポンシブ）
- OGP・メタディスクリプション・ローカルビジネス構造化データ（JSON-LD）出力
- プラグイン不要で動作（画像素材も不要）
- 既存のブログテーマ（kitaspo-blog）とは独立して動作します
